#   text:X      -> rendered text runs must contain X

#   blockw:tag:W -> first block of that tag is at least W wide

#   computed:SEL:PROP=VALUE -> the cascaded value of PROP on the first element

#                              (e.g. computed:#a:display=block, computed:p:font-size=16px,
#                              computed:.box:margin-top=0px, computed:#x:width=50%)
#                              supported PROPs: display color background-color font-size
#                              font-weight line-height width height margin-top margin-left
#                              padding-top padding-left position opacity text-align
#                              visibility border-radius; an unknown PROP fails the check
#   pixel:X,Y=RRGGBB -> paint the page into a 1000x700 canvas and read that
#                     pixel; ±2 per channel. The only check that proves what the
#                     rasterizer produced.
#   runfont:FAMILIA -> some text run asks for FAMILIA (any entry of its
#                     font-family list, compared without case and quotes)
#   boxdiff:SEL_A:SEL_B:MIN -> the two boxes differ in width by at least MIN px
#   attr:SEL:NAME=VALUE -> the first element matching SEL has attribute NAME = VALUE
#                          (e.g. attr:input[type=checkbox]:checked=, attr:a:href=/x)
#   choose:SEL=TEXTO -> open that <select> and pick the option with that label
#   submit:SEL=METHOD[:BODY] -> click the control and check the navigation it
#                     asked for (METHOD `get` or `post`, BODY a substring)
#   blocked:TRECHO -> a subresource was refused by the origin policy (mixed
#                     content, file:// reaching the network, or CSP)
#   selection:x1,y1,x2,y2=TEXTO -> drag a selection and check the text it yields
#   served[:motivo] -> the case needs a real origin (`--serve`); on file:// it
#                     is counted as unsupported instead of failing
#   nojsrerror   -> no JS error recorded
#   unsupported:reason -> case is known-unsupported, counted separately
